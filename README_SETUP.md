# Setup Instructions

It seems I'm unable to run commands directly in your environment. Here is how you can set up and run the application manually.

## Prerequisites

Ensure you have **Node.js** (and `npm`) or **Bun** installed.
Since a `bun.lock` file exists, this project was likely initialized with Bun.

## Option 1: Using Bun (Recommended if installed)

1.  Open your terminal in the project folder:
    `c:\Users\robso\Dropbox\Vinutto\Avaliacao`
2.  Install dependencies:
    ```bash
    bun install
    ```
3.  Start the development server:
    ```bash
    bun dev
    ```

## Option 2: Using npm

1.  Open your terminal in the project folder.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```

## Accessing the App

Once the server is running, open your browser to the URL shown in the terminal (usually `http://localhost:5173` or similar).
